# Om Lad - Personal Portfolio

A personal portfolio website built with HTML and CSS to showcase my projects, skills, education, and achievements.

## Features
- **Responsive Design**: Adapts beautifully to mobile, tablet, and desktop screens.
- **Modern Aesthetics**: Utilizes glassmorphism, dynamic animations, and clean layouts.
- **Sections**:
  - **About Me**: Brief introduction and skills toolbox.
  - **Education**: Details about my B.Tech and Diploma studies.
  - **Projects**: A curated list of my real-world and experimental projects.
  - **Achievements**: Certifications and hackathon participations.

## Tech Stack
- HTML5
- Custom CSS (Variables, Flexbox, Grid, Animations)
